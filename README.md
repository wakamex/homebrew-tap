# wakamex/homebrew-tap

[Homebrew](https://brew.sh/) tap (`wakamex/tap`) for packages published by `wakamex`. Each cask and formula points to an immutable GitHub Release archive and its `SHA256SUMS` digest.

## Usage

```sh
brew tap wakamex/tap
brew install --cask wakamex/tap/wakterm
```
